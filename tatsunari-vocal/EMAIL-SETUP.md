## フォームからの自動通知に必要な設定

GitHub Pages 上の静的ページだけではサーバーからメールを送れません。以下は未設定です。

1. フォーム送信サービス、またはサーバー側の予約受付 API を用意する。
2. 送信サービス側で通知先 1641494papa@gmail.com を登録し、必要な受信先確認を完了する。自前 API の場合は送信元アドレス／ドメインの認証、メール送信サービスの認証情報をサーバー側に設定する。認証情報を公開ソースに書かない。
3. API 側で第1〜第3希望、連絡先等を検証し、通知先を固定する。公開サイトからの受付、迷惑送信対策、送信失敗時の応答を設定する。
4. app.js の mailto 作成処理を API への送信に置き換える。成功応答が確認できた場合のみ受付を表示し、失敗時は入力を保持して再試行・LINE相談を案内する。
5. 実際のメール到着まで確認する。受付と予約確定は区別し、日時は講師の返信で確定する。

現在は送信サービス契約・認証情報・受信確認がないため、自動送信もメール到着確認も行っていません。

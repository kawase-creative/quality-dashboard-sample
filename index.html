工程内不良モニター(見本)

Manual / UI・UX Design

1. 検索条件を指定

1

拠点・ライン群・検査者・開始日・終了日を指定します。初期表示は開始日・終了日ともに「昨日」です。

2

「検索」を押すと、最上段KPIと全チャートが指定条件で再集計されます。

2. KPIの見方

最上段の「良品数・不良数・不良率・現在の評価」は、上部検索条件のみを反映します。チャートクリックによる掘り下げ条件では変化しません。

☀ 0～1.9999%：GOOD
☁ 2～4.9999%：WARNING
☂ 5%以上：BAD

3. パレート図の見方

不良内容を件数の多い順に表示します。赤い棒は累積80%に到達するまでの重点不良です。赤い折れ線は累積比率、オレンジ破線は80%ラインです。

重点項目は件数や検索条件に応じて自動で変わります。

4. チャート連動

不良内容・品番・ライン・仕上の棒グラフをクリックすると、ほかのチャートと不良明細が連動して絞り込まれます。同じ棒をもう一度クリックすると、その条件だけ解除されます。

上部の「チャート絞り込み解除」で、チャート選択を一括解除できます。

5. 不良明細

指定期間内の不良データを全件表示します。チャートで絞り込んだ場合は、その条件に該当する明細だけが表示されます。

6. CSVダウンロード

「CSVダウンロード」を押すと、現在表示中の不良明細をCSVで保存できます。検索条件・チャート選択の両方を反映したデータが出力対象です。

UI / UX コンセプト

「異常の発見 → 原因の絞り込み → 明細確認 → データ出力」を1画面で完結させることを目的とした品質分析ダッシュボードです。

  • 視認性： 白背景＋淡いグレーをベースに、異常・重点箇所だけ赤で強調。
  • 一貫性： すべての分析カードを同じ角丸・余白・タイトル階層で統一。
  • 直接操作： グラフそのものをフィルターとして使えるクロスフィルタ型UI。
  • 認知負荷低減： KPIは全体状態、チャートは掘り下げ分析という役割を分離。
  • 復帰性： 選択条件を可視化し、一括解除できるため迷子になりにくい。

デザイントークン

配色はデンソーのコーポレートイメージを基準に設計し、社内システムとしての視覚的な統一感を確保しています。強調色と通常色の役割を明確に分けることで、ブランド性と情報判読性の両立を図っています。

DENSO Red#E60012

デンソーレッドを採用。重点不良・警告・注目情報に用いることで、企業ブランドとの視覚的な一貫性を保ちながら、重要情報を直感的に認識できる設計としています。

Action Green#16A34A

検索・CSVダウンロードなど、ユーザーが能動的に実行するアクションに使用。初期案では赤色も検討しましたが、グラフの強調色と競合して操作ボタンがデータ表現の一部に見えやすい傾向があったため、A/B比較の結果グリーンを採用しました。データを示す色と、操作を促す色を明確に分離することで、視認性と操作性の両立を図っています。

Crafting Blue#91BEE8

デンソーのCrafting Blueを採用。通常データや比較対象に使用し、デンソーレッドとのコントラストで情報の優先度を明確化。社内ツールとしての統一感と親和性を高めています。

コンポーネント設計

要素役割設計意図
KPIカード全体状態の把握チャート連動から切り離し、基準値として固定。
パレート図重点不良の特定累積80%を赤で明示し、優先順位を瞬時に判断。
品番 / ライン / 仕上原因の切り口クリック操作で他チャートと明細をクロスフィルタ。
選択チップ現在条件の可視化「今どこまで絞っているか」を常時把握。
不良明細事実確認集計結果から実データへ自然にドリルダウン。
CSV二次利用会議資料・Excel分析へそのまま持ち出せる。

③ パレート図確認

④ クロスフィルタ
